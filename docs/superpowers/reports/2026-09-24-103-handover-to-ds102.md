## Two traps 103 hit that will cost you time

1. **`gh pr edit --body-file` silently does nothing on this repo** (Projects-classic
   GraphQL deprecation). It prints success-looking output and changes nothing.
   Use `gh api -X PATCH repos/<owner>/<repo>/pulls/<n> -F body=@file`, then read
   the body back.
2. **A placeholder `## CLASS NN (assigned at merge)` heading makes the branch RED** —
   `kernel/checklist_numbers_test.go` on dev fatals on that exact string and
   asserts header == max heading. Keep class text outside the repo until you have
   numbers, then land it numbered in one commit.
